## 📖 Sobre o projeto

O **Student Manager** é um sistema de gerenciamento escolar desenvolvido inteiramente em Python, com interface via terminal.

O projeto permite cadastrar alunos, gerenciar notas e turmas, consultar boletins individuais e visualizar estatísticas gerais da escola.

Seu principal objetivo é aplicar conceitos fundamentais de programação em um sistema com diferentes funcionalidades, explorando a organização do código, a modularização e a resolução de problemas reais.

Além disso, o Student Manager funciona como um projeto de aprendizado contínuo, com a possibilidade de evoluir futuramente para uma aplicação com banco de dados e interface gráfica.

---

## 🚀 Funcionalidades

### 👨‍🎓 Gerenciamento de alunos

- Cadastrar novos alunos.
- Listar todos os alunos cadastrados.
- Consultar boletins individuais.
- Adicionar e alterar notas.
- Editar o nome e a turma de um aluno.
- Remover alunos cadastrados.

### 🏫 Gerenciamento de turmas

- Consultar as turmas cadastradas.
- Visualizar os alunos de uma turma específica.
- Consultar a quantidade de alunos por turma.
- Desenvolver um ranking de desempenho entre turmas.

### 📊 Estatísticas escolares

- Quantidade total de alunos cadastrados.
- Média geral das notas da escola.
- Quantidade de alunos aprovados.
- Quantidade de alunos reprovados.

## 💻 Como executar

### Pré-requisitos

- Python 3 instalado.
- Git instalado (opcional).

### 1. Obtenha o projeto

Clone o repositório utilizando o comando:

```bash
git clone URL_DO_SEU_REPOSITORIO
```

Ou baixe os arquivos diretamente pelo GitHub.

### 2. Acesse a pasta

```bash
cd Student-Manager
```

### 3. Execute o programa

```bash
python main.py
```

> Caso o arquivo principal tenha outro nome, substitua `main.py` pelo nome correspondente.

## 🧠 Conceitos praticados

O desenvolvimento do Student Manager proporciona a aplicação prática de diferentes fundamentos da linguagem Python:

**Estruturas de dados:** armazenamento e manipulação de informações utilizando listas e dicionários.

**Lógica de programação:** construção de menus, condições, cálculos e regras para gerenciamento escolar.

**Funções e modularização:** divisão das funcionalidades para facilitar a organização, a leitura e a manutenção do código.

**Tratamento de erros:** utilização de `try` e `except` para lidar com entradas inválidas e evitar encerramentos inesperados.

**Organização de projetos:** desenvolvimento de um sistema com múltiplas funcionalidades, preparado para futuras melhorias.
