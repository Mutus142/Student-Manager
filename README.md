🎓 Student Manager

O Student Manager é um projeto desenvolvido em Python com o objetivo de praticar e aprimorar os fundamentos da programação. O sistema funciona inteiramente no terminal e permite o gerenciamento de alunos, notas, turmas e estatísticas escolares de forma simples e intuitiva.

Além do aprendizado da linguagem Python, o projeto também foi criado para desenvolver habilidades em lógica de programação, organização de código e resolução de problemas.

🚀 Funcionalidades
Gerenciamento de Alunos
Cadastrar alunos;
Adicionar notas;
Listar todos os alunos cadastrados;
Consultar boletins individuais;
Editar informações dos alunos:
Alterar nome;
Alterar notas;
Alterar turma;
Remover alunos.
Análise de Turmas
Procurar turmas cadastradas;
Visualizar os alunos pertencentes a uma turma;
Exibir a quantidade total de alunos por turma;
Ranking das turmas (em desenvolvimento).
Estatísticas Gerais
Total de alunos cadastrados;
Média geral das notas da escola;
Quantidade de alunos aprovados;
Quantidade de alunos reprovados.
🎯 Objetivos do Projeto
Praticar os fundamentos da linguagem Python;
Desenvolver a lógica de programação através de problemas reais;
Aprender a estruturar projetos maiores dividindo funcionalidades em módulos;
Evoluir o projeto futuramente para utilização com banco de dados e uma interface gráfica.
🛠️ Tecnologias Utilizadas
Python 3;
Estruturas de dados (listas e dicionários);
Funções e modularização;
Condicionais (if, elif e else);
Laços de repetição (for e while);
Tratamento de exceções (try e except);
Git e GitHub para versionamento do projeto.
